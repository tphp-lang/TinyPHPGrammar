# 枚举对象

枚举是一组命名常量的集合，用于表示一组相关的值。

## 枚举声明
```php
// 默认从0开始的整型值
enum Color
{
    case Red;
    case Green;
    case Blue;
}

function main(): void {
    $c = Color::Red;
    println($c); // Color::Red
    println($c->name); // Red
    println($c == Color::Red); // 输出 true
}
```

一般格式：`enum` 名称:类型(可选) { `case` 常量 = 值(可选)}

## 自定义枚举值

默认情况下，枚举值从 0 开始递增。可以为枚举成员指定自定义整数值。

```php
enum HttpStatus {
    case Ok = 200;
    case NotFound = 404;
    case InternalServerError = 500;
}

function main(): void {
    $status = HttpStatus::Ok;
    println($status); // HttpStatus::Ok
    println($status->value); // 200
}
```

## 枚举类型

```php
enum Color: string
{
    case Red = 'red';
    case Green = 'green';
    case Blue = 'blue';
}

function main(): void {
    $c = Color::Red;
    println($c->value); // red
}
```

## 枚举方法

枚举对象可以定义 常量、方法和静态方法(public|private)。

```php
enum Color:string
{
    case Red = 'red';
    case Green = 'green';
    case Blue = 'blue';

    public Color DEFAULT = Color::Red;  // 常量

    public function rgb(): int[] {
        return match($this) {
            self::Red => [255, 0, 0],
            self::Green => [0, 255, 0],
            self::Blue => [0, 0, 255],
        };
    }

    public static function active(): Color[] {
        return [self::Red, self::Green];
    }
}

function main(): void {
    println(Color::Red->rgb()); // [255, 0, 0]
    println(Color::active()); // [Red, Green]
    println(Color::DEFAULT); // Color::Red
    println(Color::DEFAULT->value); // red
    println(Color::DEFAULT->name); // Red
}
```

## 枚举遍历

```php
enum Color {
    case Red;
    case Green;
    case Blue;
}

function main(): void {
    for(Color::values() as $color) {
        println("{$color->name} = {$color->value}");
    }
    // 键值对遍历：键为成员名，值为枚举成员
    for(Color::values() as $name => $color) {
        println("{$name} = {$color->value}");
    }
}
// 输出:
// Red = 0
// Green = 1
// Blue = 2
```

## 枚举参数

枚举对象可以作为参数传递给函数或者返回。

```php
enum Color {
    case Red;
    case Green;
    case Blue;
}

function printColor(Color $color): void {
    println($color->name);
}

function main(): void {
    printColor(Color::Red); // Red
}
```

## 枚举限制
> - 不允许任何属性(含静态属性)
> - 不允许构造/析构方法
> - 不允许克隆 ( 天然单例 )
> - 不能 `new`, 只能通过 `::` 调用
> - 不能继承，也不能被继承
> - 枚举中，声明的类型必须一致，值不可重复
