# 类&对象

类是对象的蓝图或模板，它定义了对象的属性和行为。对象是类的实例，具有类的属性和行为。

## 术语定义

| 术语                 | 定义                                                           |
| :------------------- | :------------------------------------------------------------- |
| 类                   | 类是对象的蓝图或模板，它定义了对象的属性和行为。               |
| 实例（instance）     | 实例是类的具体实现，它具有类的属性和行为。                     |
| 实例化               | 通过 `new` 运算符创建实例的过程。                              |
| 成员（member）       | 类体内声明的属性、方法、类常量的统称。                         |
| 属性（property）     | 隶属于实例或类的变量，亦称「成员变量」。                       |
| 方法（method）       | 隶属于类的函数。                                               |
| $this                | 在实例方法内指向当前调用对象的伪变量。                         |
| 可见性（visibility） | 对成员访问作用域的约束，由 public / protected / private 指定。 |
| 范围解析操作符 ::    | 用于访问类常量、静态成员、静态方法。                           |
| 对象运算符 ->        | 用于访问实例的属性与方法。                                     |

## 可见性

| 修饰符    | 可访问作用域                                 |
| :-------- | :------------------------------------------- |
| public    | 任意作用域；未显式书写时的默认值             |
| protected | 声明类、其子类及父类内部                     |
| private   | 仅限声明该成员的类内部（子类亦不可直接访问） |

## 类的定义

```php
// 关键字 class , 名字首字母习惯大写.
class Dog {

    // 属性： 访问修饰符 类型 var(可选) $变量名 = 默认值;
    public string var $name = "旺财";

    // 常量： 访问修饰符 类型 const(可选) 常量名 = 常量值;
    public string const TYPE = "狗";

    // 方法： 访问修饰符 function 方法名(参数): 返回类型;
    public function bark(): void {
        println("{$this->name}:汪汪汪!");
    }
}

function main():void {
    $a = new Dog();
    $b = new Dog();

    $a->name = "小黑"; // 读作"的"，改的是 a 这只狗的 name 属性
    $b->name = "小白"; // b 完全不受影响
    // 属性可变,不可增加或删除

    $a->bark(); // 小黑：汪汪！
    $b->bark(); // 小白：汪汪！
}
```

## 语法概要

```php
class ClassName [extends ParentClass] [implements InterfaceName, ...]
{
    // 类常量
    [public|protected|private] type [const] NAME = value;

    // 属性
    [public|protected|private] type [var] $property = value;

    // 方法
    [public|protected|private] [static] function method(type $arg): returnType
    {
        // 方法体
    }
}

function main():void {
    $obj = new ClassName(args);   // 实例化
    $obj->property;               // 访问实例属性
    $obj->method();               // 调用实例方法
    ClassName::CONSTANT;          // 访问类常量 / 静态成员
}
```

## 属性、常量声明

属性值可变，常量值不可变。

```php
class User
{
    public string $name;              // 类型属性，无默认值 → 初始化状态为 空字符串,按照变量默认值以此类推
    public int $age = 0;              // 含默认值 → 初始化为 0

    public string const TYPE = "人";  // 常量属性，不可变 。不可无值无类型声明
    // 和普通常量定义机制一样,仅作用域不同
}
```

## 方法与`$this`

```php
class Counter
{
    private int $n = 0;

    public function increment(): int
    {
        $this->n++;      // $this 指向调用该方法的实例
        return $this->n;
    }
}

function main():void {
    $c1 = new Counter();
    $c2 = new Counter();
    println($c1->increment());   // 1
    println($c1->increment());   // 2
    println($c2->increment()); // 1  ← 与 $c1 状态隔离
}
```

约束

- `$this` 仅在非静态实例方法中可用；在类外、普通函数或静态方法中出现将导致 Error（静态方法应使用 `self:: / static::`）。
- 属性访问写作 `$obj->prop`，方法调用写作 `$obj->method()`；-> 后不加 `$`。误写为 `$obj->$prop` 将按可变变量解析。

## 构造函数`__construct`与析构函数`__destruct`

构造函数和析构函数是不返回任何类型的,所以不用写`返回类型声明`。

构造函数和析构函数,可以不写但会默认一个`空函数`存在,写了则覆盖默认函数。

```php
class Counter
{
    private int $n = 0;

    public function __construct(int $n)
    {
        $this->n = $n;
    }

    public function increment(): int
    {
        $this->n++;
        return $this->n;
    }

    public function __destruct()
    {
        println("Counter {$this->n} is destroyed.");
    }
}

function main():void {
    $c1 = new Counter(1); // 构造函数
    // new Counter(); // 报错,缺少必须参数
    $c1->increment();
    $c1->increment(); // 当对象使用完毕后,析构函数自动被调用,并且释放资源
    // Counter 3 is destroyed.
    
}
```

## 类常量、静态成员与 `::`

以 `static` / 常量的成员归属于类本身，在全部实例间共享单一存储。

```php
class Dog
{
    public const LEGS = 4;             // 类常量，不可修改
    public static int $count = 0;      // 静态属性，可变

    public string $name;               // 实例属性，每对象一份

    public function __construct(string $name)
    {
        $this->name = $name;
        self::$count++;                // 类内引用自身静态成员
    }

    public static function total(): int
    {
        return self::$count;           // 静态方法中不可用 $this
    }
}

function main():void {
    println(Dog::LEGS);          // 4
    println(Dog::$count);        // 0

    new Dog('小黑');
    new Dog('大白');

    println(Dog::total());       // 2
    println((new Dog('花花'))->name);   // 花花
}
```

内引用关键字

|    写法    |                   含义                    |
| :--------: | :---------------------------------------: |
|  `self::`  |             定义当前成员的类              |
| `parent::` | 定义当前成员的父类,常用于调用被重写的方法 |

| 操作符 |               左操作数                |                含义                |
| :----: | :-----------------------------------: | :--------------------------------: |
|  `::`  | `类名` / `self` / `parent` / `static` | 用于访问类常量、静态成员、静态方法 |
|  `->`  |               对象实例                |         实例属性、实例方法         |

## 继承与重写

使用 ``extends`` 建立父子类关系。TPHP 为单继承：一个类只能有一个父类，可通过 `implements` 实现多个接口。

```php
class Dog
{
    
    public string $name;

    public function __construct(string $name) {
        $this->name = $name;
    }

    // 简写
    // public function __construct(public string $name) {}

    public function bark(): void
    {
        println("{$this->name}：汪汪！");
    }
}

// 继承 extends 
class GuardDog extends Dog
{
    public function guard(): void
    {
        println("{$this->name} 在门口警戒");
    }

    // 重写（override）：签名须与父类兼容
    public function bark(): void
    {
        println ("{$this->name}：汪！汪汪！（警戒）");
        // parent::bark();   // 如需复用父类实现
    }
}

function main():void {
    $d = new GuardDog('阿黄');
    $d->name;      // '阿黄'  ← 继承自 Dog
    $d->bark();    // 阿黄：汪！汪汪！（警戒）
    $d->guard();   // 阿黄 在门口警戒
}
```

规则

- 子类继承父类的 `public` 与 `protected` 成员；`private` 成员不被子类直接访问。
- 重写时参数类型和返回类型不可变，否则错误。

常见错误对照

|              写法               |             结果              |
| :-----------------------------: | :---------------------------: |
|          `Dog::bark()`          | Error：非静态方法不可静态调用 |
| `println($this->name;)`（类外） |    Error：$this 上下文无效    |
|          `$d->name()`           |     Error：name 不是方法      |
|     `$d->age = 18;`(未声明)     |    Error：为声明`age`属性     |
