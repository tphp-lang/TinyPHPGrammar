# TPHP 基本类型

|   类型   |                描述                |
| :------: | :--------------------------------: |
|  `bool`  |                布尔                |
| `string` |               字符串               |
|   `i8`   |           8位有符号整数            |
|  `i16`   |           16位有符号整数           |
|  `i32`   |           32位有符号整数           |
|  `i64`   |           64位有符号整数           |
|   `u8`   |           8位无符号整数            |
|  `u16`   |           16位无符号整数           |
|  `u32`   |           32位无符号整数           |
|  `u64`   |           64位无符号整数           |
|  `int`   |           别名`i32`类型            |
|  `null`  |              空值类型              |
|  `void`  | 空类型: 通常用于无类型返回函数声明 |
|  `f32`   |             32位浮点数             |
|  `f64`   |             64位浮点数             |
| `float`  |           别名`f32`类型            |
