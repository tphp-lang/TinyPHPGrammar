# TinyPHPGrammar

TPHP（TinyPHP）语言语法文档。TPHP 是一门**编译型、静态类型**的语言，语法形态借鉴 PHP，编译目标为 C。

## 定位

| 维度 | 说明 |
| :--- | :--- |
| 类型系统 | 静态类型，编译期检查，无隐式类型转换 |
| 执行模型 | 编译型，无解释器 |
| 内存管理 | 引用计数，确定性析构，无 GC 停顿 |
| 空值安全 | 可空类型 `?T`，编译期强制判空 |
| 错误处理 | `?T` / `!T` + `or { }` 块，无异常 |
| 文件后缀 | `.tp` |
| 入口 | `function main(): void`，与 C 一致 |

TPHP 不需要 `<?php ?>` 包裹，也没有游离代码 —— 每个 `.tp` 文件只有声明与函数定义。

本规范只覆盖**语言语法**。字符串缓冲、文件与 JSON 之类的 I/O、以及 `Map` / `Set` 这类键值容器属于**标准库**，不在本规范范围内 —— 语言的数组只有整数索引（见 [08. 数组](08.数组arrays.md)），需要键值容器时由标准库提供。

## 四种类型声明

| 声明 | 语义 | 内存 | 用途 |
| :--- | :--- | :--- | :--- |
| `class` | 引用语义 | 堆 + 引用计数 | 有身份、有行为的对象 |
| `struct` | 值语义 | 栈或内联 | 一组相关的数据 |
| `interface` | 纯契约 | 胖指针 | 抽象行为，多态 |
| `enum` | 枚举 | 单例集合 | 一组命名常量 |

## 快速上手

```php
// main.tp
function main(): void {
    println("Hello World");
}
```

输出：

```
Hello World
```

## 最小示例

```php
struct Point {
    public f64 $x;
    public f64 $y;

    public function length(): f64 {
        return sqrt($this->x * $this->x + $this->y * $this->y);
    }
}

function main(): void {
    $p = Point(3.0, 4.0);
    println($p->length());        // 5.0

    $scores = [90, 85, 77];
    $avg = $scores->sum() / $scores->length();
    println("avg = {$avg}");

    $found = $scores->get(10) or { 0 };
    println($found);              // 0
}
```

## 与其他语言的关系

借鉴来源与取舍原则：

| 来源 | 借鉴 |
| :--- | :--- |
| PHP | 语法形态（`$` 前缀、`->`、`::`、约定） |
| C | 入口函数、强类型纪律、`struct` 值语义、编译目标 |
| Rust | 显式类型转换、名义类型、不引入异常 |
| Swift | 引用计数与确定性析构、值语义 |
| Zig | 最小化语法糖，避免隐式行为 |

## 设计原则

1. **性能可预测** —— 同一段代码的代价不随运行时数据变化（浅拷贝而非深拷贝、拒绝 COW 数组）。
2. **编译期能查清的绝不留给运行期** —— 类型、空值、数组越界、格式串匹配。
3. **错误写在签名上** —— `?T` / `!T` 让调用方不必阅读实现就知道如何处理失败。
4. **规则宁可少而一致** —— 四类声明、一套访问符 `->`、单一循环关键字 `for`。
